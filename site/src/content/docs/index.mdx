## An open invitation

A familiar box, built for a space full of possibilities. Four flaps invite the next project, a clear
structure gives every part a place, and the colours do the rest: teal grounds it, orange gets it moving.

## What's new in v2.0

<div class="sw-home-split">
<div>

Version 2.0 of the design system ships alongside SpaceWorks 0.12.0. The headline changes:

- **A solid-black dark mode.** One neutral black family, with the brand brights unchanged in both themes.
- **The logo moves.** The box opens on hover and focus, and the same box is the loader everywhere.
- **A motion kit.** Every animation in the product as a reusable template: CSS, React copies, a live demo and a README.
- **Brand guidelines v2.** A 50-page book covering light and dark, motion and the product.
- **Product rules.** The rules every Space Works product follows, and where each product stands.

## One source of truth

Everything on this site is published straight from the
[SpaceWorks-Design-System](https://github.com/SpaceWorks-Labs/SpaceWorks-Design-System) repository. Add it to any Space Works
project as a git submodule and every surface draws from the same kit:

```bash
git submodule add https://github.com/SpaceWorks-Labs/SpaceWorks-Design-System.git design
```
