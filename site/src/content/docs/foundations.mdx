Foundations are the values every screen is built from. They live in [`tokens/`](https://github.com/SpaceWorks-Labs/SpaceWorks-Design-System/tree/main/tokens)
as CSS variables and JSON, and are the same in the web app, the sibling apps and the native apps. Use a token,
never a typed-in value: that is what keeps light and dark, tenant colours and reduced motion working.
