## Two fonts. Clear roles.

Gilroy ExtraBold leads display type. Outfit does the everyday work. Unbounded brings the bold geometric accent.

## Font files

The web fonts live in [`fonts/`](https://github.com/SpaceWorks-Labs/SpaceWorks-Design-System/tree/main/fonts) and
are wired up by `tokens/tokens.css`:

| File | Face |
|---|---|
| `Gilroy-Light.woff2`, `Gilroy-ExtraBold.woff2` | Gilroy 300, 800 (the free weights, Gilroy free-font EULA) |
| `Outfit-Variable.woff2` | Outfit 400-700 (SIL Open Font License) |
| `Unbounded-Variable.woff2` | Unbounded 500-600 (SIL Open Font License) |

:::note[Only the free Gilroy weights ship]
Gilroy Regular, Medium, SemiBold and Bold are paid weights and are not distributed. Use Outfit for
everything that is not a display heading. See the [credits](/about/credits/) for licences.
:::
