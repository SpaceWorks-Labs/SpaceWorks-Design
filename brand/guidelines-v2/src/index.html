Flaps are stepped, never interpolated. Each flap's matrix() is sampled 160 times per cycle and played with steps(1, end). Browsers glitch when they blend two matrices near edge-on.

space works / brand guidelines05 / TYPOGRAPHY
Design System v2.0 · Brand guidelines v225

Two free weights. No exceptions.

Only the free Gilroy weights ship. Everything else is set in Outfit. This replaces the four-weight Gilroy of v1.

Gilroy ExtraBold · 800 · free
Ready to make.
Gilroy Light · 300 · free
Everything in its place.
Withdrawn · paid weights, no licence held
Regular 400 Medium 500 SemiBold 600 Bold 700
Why

Gilroy is a commercial family. Its author releases Light and ExtraBold free, under an EULA that allows websites (@font-face), graphics, print and embedding in software. Regular to Bold are paid. The project does not hold that licence, so those files were removed from every repository (decision 299, 11 November 2026) and are never re-added.

What fills the gap

Outfit (SIL OFL, variable 400–700) takes every role between the two Gilroy weights: body, labels, buttons, table text, numbers and IDs. Unbounded (OFL) keeps its one accent phrase.

Never
  • Ask the browser for a Gilroy weight that does not ship. Set font-synthesis: none.
  • Fake a middle weight with a stroke, a shadow or faux bold.
  • Download a paid weight “just for a mock-up”.

space works / brand guidelines07 / MOTION
Design System v2.0 · Brand guidelines v232

Motion shows what changed.

It never decorates. If removing an animation loses no information, keep it short or drop it.

  1. 01Animate content, not chrome. On a page change only the main area moves; sidebar and top bar stay still.
  2. 02Transform and opacity only. No layout properties. Collapses use grid rows 0fr to 1fr, never height.
  3. 03Enter decelerates, exit accelerates, and exits are shorter than entrances.
  4. 04Nothing on an interaction path runs longer than 240 ms. Longer motion is page- or brand-level and never blocks input.
  5. 05Hover is colour only, 120 ms. No lift, scale or shadow. The Space Works mark is the single exception.
  1. 06One loader: the box that opens. Never loop anything else, except two decorative touches that reduced motion switches off.
  2. 07Reduced motion is a floor, not a flag. Every animation has a still version that carries the same information.
  3. 08No hover animation on touch. Gate on @media (hover: hover); keyboard focus still plays.
  4. 09Both themes, every time. Motion is colour-neutral, so it behaves the same in light and dark.
  5. 10Never block navigation on an animation. A slow page settles after 160 ms and the route goes on.

space works / brand guidelines10 / PRODUCT
Design System v2.0 · Brand guidelines v243

Product rules, in short.

What every Space Works product follows, from the main app to the phone apps.

Areas

Everything optional is an area with one registry key. Off means gone everywhere. Switching off keeps data; purge is a separate, deliberate step.

Role views

Permissions are actions, not role names. Each person sees only what their role holds; the server refuses too.

One space, one scope

Every record belongs to one space and every query is scoped. Public pages never show locations, QR codes or evidence.

Audit trail

Every state change writes an append-only audit entry. Evidence is immutable. No issue without a scan and a photo.

Money

Record the debt first, add a payment rail second. Minor units with currency, never floats. Idempotent, and the ledger is permanent.

Analytics

Counts only: how many, by channel and day, never who. Web, iOS, Android and API clients are tagged.

API

Every endpoint in OpenAPI with typed errors. The same authority on web and native tokens; 429 with Retry-After.

Code size

About 200 lines per file, 300 at most. Split by responsibility behind a thin barrel; split first, then add.

Install in one line

One command asks every question first, changes nothing until you confirm, and runs again to update.

Hosted or hybrid

One space, many spaces, or a platform. The website can live here or elsewhere with this as the API.

Words

Every string translated as a whole sentence with real plurals. Error codes stay stable; messages translate.

Tests

Test what people can observe. The baseline is zero failures, and no test is ever deleted.
