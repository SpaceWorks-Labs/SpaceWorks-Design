Version

Space Works Design System v2.0 · Brand guidelines v2, November 2026. Ships alongside SpaceWorks 0.12.0. Supersedes brand guidelines v1 wherever the two differ; everything v1 says that this book does not change still stands.

Sources

Colours, ratios and motion values are read from tokens/tokens.json when the book is built. Frames of the box are frozen from motion/box-open/box-open.css. Decisions cited: 225, 299, 313, 316, 322, 323, 362.

Set in

Gilroy ExtraBold and Gilroy Light (free weights), Outfit and Unbounded (SIL OFL).

Built from

HTML and CSS in brand/guidelines-v2/src/, rendered with headless Microsoft Edge. Rebuild with node brand/guidelines-v2/build.mjs.
