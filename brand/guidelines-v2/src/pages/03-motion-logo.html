Loader: open, hold, fold, repeat.

A 4400 ms cycle for anything that loads for an unknown time. It replaces ring spinners and skeleton shimmer.

Flaps are stepped, never interpolated. Each flap's matrix() is sampled 160 times per cycle and played with steps(1, end). Browsers glitch when they blend two matrices near edge-on.

Colours per theme. Box faces are the masters' own colours. Under-face {{hex:loader.light.under}} light, {{hex:loader.dark.under}} dark; spark {{hex:loader.light.spark}} / {{hex:loader.dark.spark}}; the dark seam is the page colour so it vanishes on black.

Fixed aspect 136 : 126. Width = height × 136 ÷ 126. The box never changes size while it plays, so nothing around it moves.

Hover and focus: fold, then open.

From the resting logo the box folds shut in 600 ms and opens back in 1600 ms. No hold, no snap at either end.

Starts on pointer-enter of a mouse or pen, or on keyboard :focus-visible. Never on touch: gate on @media (hover: hover).

Always finishes. Leaving mid-way lets it finish; re-entering while it plays does not restart it. It never loops.

Reduced motion shows the still mark. The mark never takes focus itself and never changes size.

One component (AnimatedLogoMark) draws every placement; a guard test fails the build otherwise. Tenant logos never animate.
