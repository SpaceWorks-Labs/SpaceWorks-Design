# Kiosk and display screens

The rules for screens that stay on all day: the space display (a rotating slide show on a Raspberry Pi), the kiosk and the stats TV. Slides change with one opacity fade; the distance tokens are zeroed so every shared animation (route, dialog, drawer, menu, toast) becomes a fade. Nothing loops and nothing keeps repainting while idle.

Open [`demo.html`](demo.html) in a browser (it links `../../tokens/tokens.css`) and use "Toggle dark" to check both themes.

## Files

| File | What it is |
|---|---|
| `kiosk-display.css` | `sw-display-fade` (400 ms slide fade) and the `.sw-kiosk, .sw-tv` token override, verbatim. |
| `demo.html` | A standalone page with the live animation in light and dark, replayable. |
| `react/` | Copies of the real app files (see `react/README.md` for the imports to replace). |
| `previews/` | Animated WebP and GIF previews, light and dark (regenerated by `scripts/make-previews.mjs`). |

## Where the app uses it

- Display slide fade: `features/spaceDisplay/display.css` (`.sw-display-fade` on each slide in the space display).
- Kiosk and TV: `.sw-kiosk` (`components/layouts/KioskLayout.tsx`) and `.sw-tv` (`features/stats/PublicStatsTvPage.tsx`) zero `--sw-enter-y`, `--sw-pop-scale`, `--sw-pop-offset`, `--sw-slide-x` in `styles/motionTokens.css`.

## Why

A small Raspberry Pi browser, a wall TV or a shared kiosk must stay idle between changes and must never move content a bystander is reading. A fade shows a change without motion across the screen; zeroing the tokens gives every component that behaviour without per-component code.

## Timing, easing and distance

| Part | Value |
|---|---|
| Slide fade | 400 ms `ease-out, opacity 0 to 1, `both` |
| Tokens inside `.sw-kiosk` / `.sw-tv` | `--sw-enter-y: 0px`, `--sw-pop-scale: 1`, `--sw-pop-offset: 0px`, `--sw-slide-x: 0%` |

## Trigger

A slide mounts or changes (key the element so the animation replays). The token override applies to everything inside the kiosk or TV wrapper.

## Reduced motion

The display fade is `animation: none`; tokens go to 0 as everywhere else.

## Dark theme

Colour-neutral; the displays use the same tokens and the black-family dark theme.

## Do and don't

- Do use fades only on shared screens.
- Do key each slide so the fade replays once per change.
- Do not slide, scale or loop on kiosk, TV or display screens.
- Do not keep anything animating while idle (no CSS loops, no timers that repaint).

## Copy-paste usage

```html
<link rel="stylesheet" href="../../tokens/tokens.css"><link rel="stylesheet" href="../overlays/overlays.css"><link rel="stylesheet" href="kiosk-display.css">
<div class="sw-kiosk"> <!-- every shared animation inside is a fade -->
  <section class="sw-display-fade" key="slide-3">…</section>
</div>
```
