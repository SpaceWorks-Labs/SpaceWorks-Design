# Sidebar and tab indicator

The current section is shown by one box that slides to the selected item, instead of each item repainting its own highlight. The same hook moves the tab underline. A resize skips the transition so a collapsing section never makes the indicator lag.

Open [`demo.html`](demo.html) in a browser (it links `../../tokens/tokens.css`) and use "Toggle dark" to check both themes.

## Files

| File | What it is |
|---|---|
| `sidebar.css` | The `.sw-indicator` box, the rules that drop the item's own highlight once the indicator is placed, and the tab underline, verbatim from the app. |
| `demo.html` | A standalone page with the live animation in light and dark, replayable. |
| `react/` | Copies of the real app files (see `react/README.md` for the imports to replace). |
| `previews/` | Animated WebP and GIF previews, light and dark (regenerated by `scripts/make-previews.mjs`). |

## Where the app uses it

- Staff and member sidebar: `components/shell/Sidebar.tsx`, `SidebarItem.tsx`, `SidebarSection.tsx` (the "More" group uses the collapse family).
- Tabs with an underline: `.desk-tab-active` and `.sw-tab-indicator` in staff panels.
- Hook: `lib/motion/useSlideIndicator.ts`.

## Why

Moving one box shows where you came from and where you are now; repainting a list item does not. It is also the cheapest possible animation: one transform.

## Timing, easing and distance

| Property | Value |
|---|---|
| `transform` | `--sw-dur-base` 180 ms, `--sw-ease-standard` |
| Size | set directly (width and height are never transitioned) |
| Resize | `transition: none` for that update |

## Trigger

A change of the current item or tab (the hook key). The container gets `data-slide` once the indicator is placed; the indicator hides when nothing matches.

## Reduced motion

The token duration is 0, so the box jumps to the new item; the current item is still marked by `aria-current`.

## Dark theme

Colours come from tokens (`--color-accent-soft` fill, `--color-accent-ink` underline).

## Do and don't

- Do transition only `transform` and set the size directly.
- Do keep `aria-current="page"` on the real item.
- Do not animate the sidebar on route changes (see route-transition).
- Do not repaint each item's highlight separately.

## Copy-paste usage

```html
<nav id="nav" style="position:relative">
  <div class="sw-indicator" id="bar"></div>
  <a class="sw-slide-item" aria-current="page">Requests</a><a class="sw-slide-item">Inventory</a>
</nav>
```

Call the placement function from `demo.html` (a plain-JS port of `useSlideIndicator`) whenever the current item changes and on resize.
