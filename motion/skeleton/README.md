# Skeleton and progress

Loading placeholders and progress. A skeleton reserves the shape of what is coming and puts the Space Works box spinner in it; it does not shimmer. A progress bar grows to its new value instead of jumping.

Open [`demo.html`](demo.html) in a browser (it links `../../tokens/tokens.css`) and use "Toggle dark" to check both themes.

## Files

| File | What it is |
|---|---|
| `skeleton.css` | The still placeholder shape and the progress-width transition. The spinner itself is the box-open loader (`../box-open/`). |
| `demo.html` | A standalone page with the live animation in light and dark, replayable. |
| `react/` | Copies of the real app files (see `react/README.md` for the imports to replace). |
| `previews/` | Animated WebP and GIF previews, light and dark (regenerated by `scripts/make-previews.mjs`). |

## Where the app uses it

- `components/ui/Skeleton.tsx` and `SkeletonRows` in `components/ui/DataTable.tsx‬ loading rows, list and card placeholders across staff and member screens.
- Progress width: `features/cards/cardJobs.tsx` (card job progress). `components/ui/ProgressBar.tsx` sets the width without a transition.

## Why

The page keeps its layout while data loads, so nothing jumps when it arrives, and the one brand-owned loading indicator tells the person something is coming. A shimmer would keep repainting an idle screen; progress that eases to its value reads as continuous.

## Timing, easing and distance

| Part | Value |
|---|---|
| Skeleton | no animation of its own; the box spinner inside loops 4400 ms |
| Progress fill | `width` 150 ms, `cubic-bezier(0.4,0,0.2,1)` (Tailwind default) |

## Trigger

A skeleton is mounted while a query loads. The progress fill transitions whenever its width changes.

## Reduced motion

The spinner shows the still, open logo; the progress width jumps to its value (the transition is inside `no-preference`).

## Dark theme

The surface and fill are tokens; the box spinner uses the reversed artwork in dark (see box-open).

## Do and don't

- Do size a skeleton to the content it replaces.
- Do put one box spinner in it, not a spinner on every row at once.
- Do not add shimmer sweeps or pulsing greys.
- Do not use a progress bar for unknown time (use the box loader).

## Copy-paste usage

```html
<link rel="stylesheet" href="../box-open/box-open.css"><link rel="stylesheet" href="skeleton.css">
<div class="sw-skeleton" style="height:56px" aria-hidden="true">
  <div class="sw-box loop" style="width:22px;height:20px"><!-- ../box-open/box-open-markup.html --></div>
</div>
<div class="sw-progress" role="progressbar" aria-valuenow="40"><div class="sw-progress-fill" style="width:40%"></div></div>
```
